# IM-Motor-Opt — Metaheuristic Design Optimization of a 5.5 kW Induction Motor

## Description
MATLAB implementation of the analytical design and optimization of a three-phase,
four-pole, 5.5 kW squirrel-cage induction motor. The analytical model follows the
Boldea induction-machine design procedure and is posed as a constrained optimization
problem with 16 design variables and 10 constraints. The design is optimized with ten
metaheuristic algorithms, each combined with eight constraint-handling approaches
(one feasibility-first rule and seven penalty functions), giving 80 combinations that
are each run 30 times (2,400 independent optimizations). Selected designs are validated
with finite-element analysis in Ansys RMxprt and Maxwell.

This repository reproduces all numerical results, tables and figures in the manuscript.

## Dataset Information
No third-party dataset is used. All data are generated by the analytical model in this
repository. The result files are:
- `results/<ALGO>_M<k>_*.mat` — per-combination outputs for each of the 80 combinations
  (`ozet` = summary, `verimCeza` = 30×2 matrix of [efficiency, total constraint violation]
  per run, `bestlerrun` = best design parameters per run, `ortalamalar` = run means).
- `Supplementary_Table_S1_80_combinations.csv` — feasibility and efficiency summary for
  all 80 combinations.
- Random seeds used for the 30 runs are archived so that every run is reproducible.

## Code Information
- `im_design_code.m` — analytical motor-design model: computes rated efficiency (objective)
  and the ten constraint violations from the 16 design variables.
- Supporting functions: `esson_sabiti.m`, `eff_hesaplama.m`, `guc_faktoru.m`, `Kst_Kf.m`,
  `Kst_Alfa_i.m`, `BmHm.m`, `iletken_capi.m` (lookup / empirical relations used by the model).
- Algorithm implementations: PSO, GWO, WOA, ABC, AAA, TSA, DSA, Jaya, FOX, LFD.
- Constraint-handling methods (Methods 1–8): Deb feasibility rule, static count penalty,
  linear-sum, squared-sum, normalized-count, Joines–Houck dynamic penalty, and two
  iteration-scaled (sigmoid) penalties.
- `run_ALL.m` — runs all 80 algorithm–method combinations for 30 seeded runs each and
  saves the per-combination result files.
- Analysis scripts — feasibility reconstruction (violation ≤ 1×10⁻⁹), descriptive
  statistics, Friedman test with Holm-corrected Wilcoxon post-hoc analysis, bootstrap
  confidence intervals, and the scripts that regenerate the tables and figures.

## Usage Instructions
1. Open MATLAB and add the repository folder (with subfolders) to the path.
2. Run a single design evaluation: `run im_design_code.m`.
3. Reproduce the full experiment: `run run_ALL.m` — this executes the 80 combinations ×
   30 seeded runs and writes the `.mat` result files to `results/`.
4. Regenerate the statistics, tables and figures with the analysis scripts.
5. Finite-element validation: open the Ansys RMxprt/Maxwell project with the optimized
   Jaya design parameters (Table 7 of the manuscript) and run the steady-state analysis.

## Methodology
Each design is evaluated by the analytical model, which returns the efficiency and the
ten constraint violations. The constraint information is folded into the objective through
the selected constraint-handling approach, and the metaheuristic updates the population
until the evaluation budget (100,000 objective evaluations, i.e., population 40 × 2,500
iterations) is reached. Each combination is repeated 30 times. A run is feasible when its
total constraint violation does not exceed 1×10⁻⁹; efficiency statistics are computed over
feasible runs only. Algorithms are compared with the Friedman test and a Holm-corrected
Wilcoxon signed-rank post-hoc analysis, and the best Jaya designs are cross-checked in
Ansys RMxprt/Maxwell.
